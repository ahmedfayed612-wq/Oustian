2 - System overview

Oustians is the private, bilingual (Arabic RTL + English LTR), mobile-first campus social app for OUST students - invite-code gated, admin-approved, installable. Stack: Next.js 16 App Router + strict TypeScript + Tailwind v4 + next-intl, backed entirely by Supabase (Auth, Postgres + RLS, Storage, Realtime), hosted on Vercel region dub1 as oustians.com (live UNVERIFIED).

Student browser (en/ar, light/dark) --> Vercel dub1 (SSR + Server Actions) --> Supabase (Auth - Postgres RLS - Storage - Realtime)
                                    \--> Storage CDN (avatars / post-media / story-media)

Routes (src/app/[locale]/): public (auth) login/signup/pending versus member shell (app) - feed, stories, groups, connections, chat, events, notifications, search, settings, profile, admin. Every mutation: zod validation -> requireApprovedMember() (or requireAdmin()) -> Postgres RPC / RLS-guarded query. Media: ticket -> direct-to-storage upload -> commit. Chat: browser-subscribed Realtime, no socket server. Absent from code: queues, cron, search engine, analytics, payments, push/email.

4 - Architecture

Request pipeline

Browser --> proxy.ts (locale + session refresh, skipped w/o cookie/env)
  --> Guard (requireApprovedMember: profiles status+role lookup)
  --> Server Action (zod) --> consume_rate_limit (auth paths) --> RPC / RLS query
  --> revalidate / router.refresh() (RSC staleTimes.dynamic 30s)

Media upload and delivery

Browser -> ticket action (auth + zod + byte-sniff for posts/stories) -> signed path
  -> direct PUT to avatars / post-media / story-media -> commit RPC -> next/image GET (30-day cache)
Known gap (SEC-001): the avatar ticket path has NO server byte-sniff (posts/stories do). Fix: reuse the media sniff in the avatar action.

Auth sequence

signup (invite code via is_invite_code_valid, pending profile) -> /pending (refresher polls)
  -> admin approval-queue -> member shell unlocked. OAuth / MFA / custom recovery UI: NOT FOUND.

Decisions and trade-offs

DecisionBenefitCost / risk
Supabase-everything, no custom serverFast campus build, Postgres-enforced rulesRLS + RPC correctness IS the security boundary
Direct-to-storage uploadsNo Vercel bandwidth, fast mediaTicket/sniff logic must be airtight (SEC-001/002)
Read-time story expiry, no cronZero opsTombstones accumulate; every query must filter (TD-002)
RSC 30s stale + refreshInstant-feeling navSlightly stale admin queues (accepted)
CSP deferred to M8Shipped fasterBaseline headers only until then (TD-004)
